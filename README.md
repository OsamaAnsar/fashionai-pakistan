# Drape PK

**One fitting room. Every brand.**

Milestone 1 of a portfolio demo for multi-brand Pakistani fashion discovery. It includes 60 typed catalogue items, responsive editorial browsing, search, brand/category/price filters, product details and official-brand redirects.

The current catalogue is illustrative: names, prices and imagery are demo data and must not be treated as live inventory.

```bash
npm install
npm run dev
```
